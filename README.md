# README

## Purpose of the Analysis

In this project, I translated a machine learning workflow from R into Python.

The main goal was to follow the same steps as the original R script and recreate the analysis in Python. This includes exploring the data, cleaning and preparing it, building a logistic regression model, and evaluating how well the model performs.

While doing this, I made sure that the results and insights from the Python version match the original R workflow as closely as possible.

---

## Python Libraries Used

I used the following Python libraries:

* pandas for loading and working with the data
* numpy for basic numerical operations
* matplotlib and seaborn for visualizations
* statsmodels to build the logistic regression model
* scikit-learn for evaluation metrics like confusion matrix

---

## How to Reproduce the Results

1. Install the required libraries:

   ```
   pip install pandas numpy matplotlib seaborn statsmodels scikit-learn
   ```

2. Open the notebook:
   `Individual_assignment_1.ipynb`

3. Run all the cells in order. The notebook is organized step-by-step:

   * data loading
   * preprocessing and cleaning
   * exploratory data analysis
   * model building
   * evaluation
